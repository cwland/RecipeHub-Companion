Culury Companion

Send recipes, links and notes from your browser to Culury.

The address you open Culury on. The browser asks once to let the extension reach it.

In Culury: Settings › API keys, name it “Culury Companion”, choose Inbox only, then Create key and paste it here. The key is kept in this browser only.

For Import to Culury (straight into your recipes, with or without AI correction). Make a second key with Recipe push access, name it “Culury Companion import”. Leave it empty to only send to the inbox.
