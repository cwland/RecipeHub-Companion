RecipeHub Companion

Send the recipe page you’re on to RecipeHub’s inbox, or import it straight in.

The address you open RecipeHub on. The browser asks once to let the extension reach it.

In RecipeHub: Settings › API keys, name it “RecipeHub Companion”, choose Inbox only, then Create key and paste it here. The key is kept in this browser only.

For Import to RecipeHub (straight into your recipes, with or without AI correction). Make a second key with Recipe push access, name it “RecipeHub Companion import”. Leave it empty to only send to the inbox.
